What this is: a client-side simulation of the real severity classification and incident logic in agent/severity.py and agent/slack_blocks.py — the severities, rationale text, and Slack message shown below are the actual values those modules produce for each mode's signals (see the tests that pin them), reproduced here in JS so this page needs no backend on GitHub Pages. The Claude tool-use call itself is not live in this demo — see the README for how the agent runs outside this page.
